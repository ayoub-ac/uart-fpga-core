# Synthesis comparison report

> **Unverified estimates.** The figures in this file have not been confirmed by a recorded, reproducible synthesis run or by hardware measurement. Treat every LUT, FF, BRAM, DSP, Fmax, throughput, latency and power figure here as an unverified estimate. Run `make synth_report` with your own toolchain to get real numbers.

Intended to be generated by `make synth_report`; the figures below are unverified
estimates, not a recorded run. Numbers are meant as post-synthesis, pre-place-and-route.
Vendor flows (Vivado / Quartus) may pack tighter than the open-source flow (not measured).

## Notes

* The dominant area is the two FIFOs (TX and RX, each `DEPTH * WIDTH`
  flops at default 16 x 9 = 144 FF per FIFO) plus the per-bit working
  state of the RX deserializer. The RX synchroniser is a 3-FF chain
  per pad. The baud generator is a single `DIV_WIDTH`-bit counter and
  a 4-bit oversample counter.
* The 16x oversampling sample-point recovery (votes0 / votes1 + a final
  XOR vote) costs ~6 LUT4 per oversampled bit (unverified estimate); flat compared to the
  FIFOs.
* The optional `uart_axi4lite.sv` wrapper adds the standard
  AXI4-Lite slave area (~600 LUT for a 7-register block; unverified estimate) on top of
  the bare core; see the sibling `axi4lite-slave-fpga-core` for the
  detailed breakdown.
* Vivado / Quartus rows are skipped automatically when those tools are
  not on PATH; with WebPACK / Web Edition installed they are intended to
  be populated from a real synth_design / quartus_sh run. No CI workflow
  exists in this repository.

## Reproduction

```
make synth_report
```
