# Synthesis comparison report

Generated by `make synth_report`. Numbers are post-synthesis, pre-place-and-route.
Vendor flows (Vivado / Quartus) usually pack tighter than the open-source flow,
so the Yosys numbers should be read as upper bounds.

| Toolchain                | Target                  | Result                       |
|--------------------------|-------------------------|------------------------------|
| Yosys 0.x synth_ice40    | iCE40 UP5K              | 340 LUT / 168 FF / 2 BRAM              |
| Yosys 0.x synth_ecp5     | ECP5 LFE5UM-25          | 339 LUT / 156 FF / 0 BRAM               |
| Yosys 0.x synth_xilinx   | Xilinx 7-series         | 412 LUT / 283 FF / 0 BRAM                |
| Vivado synth_design      | Artix-7 xc7a35tcsg324-1 | (skipped: vivado not on PATH)             |
| Quartus Pro              | Cyclone V 5CSEMA5F31C6  | (skipped: quartus_sh not on PATH)            |

## Notes

* The dominant area is the two FIFOs (TX and RX, each `DEPTH * WIDTH`
  flops at default 16 x 9 = 144 FF per FIFO) plus the per-bit working
  state of the RX deserializer. The RX synchroniser is a 3-FF chain
  per pad. The baud generator is a single `DIV_WIDTH`-bit counter and
  a 4-bit oversample counter.
* The 16x oversampling sample-point recovery (votes0 / votes1 + a final
  XOR vote) costs ~6 LUT4 per oversampled bit; flat compared to the
  FIFOs.
* The optional `uart_axi4lite.sv` wrapper adds the standard
  AXI4-Lite slave area (~600 LUT for a 7-register block) on top of
  the bare core; see the sibling `axi4lite-slave-fpga-core` for the
  detailed breakdown.
* Vivado / Quartus rows are skipped automatically when those tools are
  not on PATH; on a CI runner with WebPACK / Web Edition installed they
  will be populated from a real synth_design / quartus_sh run.

## Reproduction

```
make synth_report
```

Raw logs land in `synth_report/`.
